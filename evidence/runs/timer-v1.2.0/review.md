# Independent timer review

Date: 2026-11-04. Reviewer: separate read-only Codex agent `timer_review`, with the owner mandate, governance and current source/tests. No builds or device operations were performed by the reviewer. Final code is committed as `4eb608db33074c2837fcc686e7227bd352ecd157`.

## Findings and resolution

1. **OBSERVED, medium, resolved:** Following reboot, continued wall-time evaluation could extend or revive remaining duration after a clock rollback. **EVIDENCE_FOR:** a 60-second timer had 25 seconds remaining at new-boot wall +35 seconds/uptime 5 seconds, then incorrectly gained time at wall +20 seconds/uptime 15 seconds. **EVIDENCE_AGAINST:** original-boot elapsed timing already resisted wall changes, and fallback was bounded to the original interval. **ALTERNATIVE_EXPLANATIONS:** intentional wall fallback was documented generally but did not guarantee monotonic progress after the first reboot read. **CONFIDENCE:** high. **MINIMAL_DISCRIMINATING_EXPERIMENT:** repeat those readings through storage recreation. **Resolution:** atomic persisted new-boot elapsed anchor, observed-expiry tombstone, strict codec validation and stale-save merge; regression tests pass.
2. **OBSERVED, medium, resolved:** The dedicated timer screen used transient paused copy during an in-flight Stop save. **EVIDENCE_FOR:** its active branch directly sampled sessionPaused; longer text could move the countdown and stop control. **EVIDENCE_AGAINST:** home already retained committed copy. **ALTERNATIVE_EXPLANATIONS:** actual text movement depends on locale/font/viewport; native rendering remains a phone check. **CONFIDENCE:** high for the code path. **MINIMAL_DISCRIMINATING_EXPERIMENT:** delay Stop persistence and compare before/during/after state. **Resolution:** shared held-status policy and a permanent viewport overlay with accessible pause announcement; state tests pass, physical rendering pending.
3. **INFERRED, medium, resolved:** Main-thread Settings.Global reads could obstruct the independent fail-open Handler. **EVIDENCE_FOR:** initial and final timer sampling queried the provider synchronously. **EVIDENCE_AGAINST:** normal provider reads are usually quick; no physical delay was measured. **ALTERNATIVE_EXPLANATIONS:** OEM/provider stalls or other platform dispatch delays. **CONFIDENCE:** medium. **MINIMAL_DISCRIMINATING_EXPERIMENT:** inspect the thread path and later measure physical dispatch. **Resolution:** primitive arrival sampling on main, provider/disk/number validation in worker, constant-time final expiry check. UI clock identity is also obtained on IO before primitive foreground sampling.
