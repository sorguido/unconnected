# C3 — Existing signing identity

Status: `OBSERVED IN SOURCE`, local secret material NOT accessed.

## OBSERVED
Repository https://github.com/sorguido/chromecast-killswitch-app has `app/build.gradle.kts` reading `development/signing.properties` and a private `storeFile`; `docs/BUILD.md` documents the keystore-based release build. The private local keystore is a PKCS#12 file under `development/`, protected by `.gitignore`. This source corroborates a reusable signing configuration, but does not make the key accessible through GitHub.

## INFERRED
The same APK signing certificate can sign other independent Android package IDs. The new Gradle build can read the Chromecast project-local signing configuration when explicitly pointed at its root.

## PROVEN / NOT PROVEN
Source configuration is confirmed. The certificate's SHA-256 fingerprint and signed unconnected APK have NOT yet been measured or compared. Do not claim they have.

## DECISION
Re-use, never copy into Git or replace, the existing signing material. Implement the contract in `docs/SIGNING.md` and verify before distributing.

Its signer SHA-256 equals the previously published Chromecast v1.1.0 APK. The local reference artifact's SHA-256 also equals GitHub's published asset digest. Full reproducible receipt: `evidence/current/signature.json`; source/command details: `evidence/current/verification.md`. This supersedes the bootstrap's unmeasured-certificate status above.
