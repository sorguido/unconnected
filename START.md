# Agent bootstrap and resume

Read the four protected canonical files **in full** in this order: `START.md`, `AGENTS.md`, `ROADMAP.md`, `CORROBORATIONS.md`. Read `PROJECT_STATE.json` and `ARTIFACT_INDEX.json` next. This file is only a context-routing entry point and does not duplicate policies or project requirements.

Inspect the actual branch, HEAD, working tree, recent commits, open gates, outputs and test evidence. Reconstruct the current phase and its first unmet exit criterion. Git history and verifiable evidence override the non-authoritative state cache; repair that cache if necessary.

Use `ARTIFACT_INDEX.json` to load only the relevant documents: usually the product specification, active phase's artifact and necessary corroboration dossiers. Avoid indiscriminate reading, repeated research, speculative alternatives and unnecessary agent reports.

Advance by the smallest reversible step that measurably satisfies an unmet roadmap criterion. Validate actual results, including real builds and tests, rather than claiming progress from documentation alone. Record decisions and verification in the appropriate non-protected artifacts.

Before ending, update the operational caches and evidence references. Follow the terminal outcomes `MILESTONE_COMPLETE`, `HUMAN_REQUIRED` or `BLOCKED` defined in `AGENTS.md`. Proceed toward the next genuine gate rather than stopping at a cosmetic milestone.
